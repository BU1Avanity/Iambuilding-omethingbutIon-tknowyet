# Daily Flow

A personal **daily chore & habit flow** web app. Add tasks (water plants, feed dogs, etc.), optional due times, check them off, and use a focus timer.

## Features

- Add chores with title, notes, and optional due time
- Live status: upcoming, due soon, overdue, done
- Checkmarks reset per day (chores stay in the list)
- Focus timer (counts down in real time)
- Saves in your browser (`localStorage`)

## Run

Open `index.html` in your browser.

## Stack

HTML, CSS, JavaScript — Stardance / Hackatime project.
